# news-image-20261119

A newspaper front page for **THE WORLD — Thursday, 19 November 2026**.

The lead story is the Shenzhen trilateral handshake: three leaders
clasping hands on the front page, the frozen moment of a deal being
sealed. Below the fold, the day's other headlines run in classic
broadsheet columns.

The entry image is `entry.png` (1024x1024). `main.py` copies it to
`/output/entry.png` byte for byte — the artwork is the entry.
